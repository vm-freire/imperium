# Imperium — Crônicas das Nações

Jogo de estratégia histórica no navegador: crie uma nação do zero (ou governe um país real), desenhe suas fronteiras num mapa-múndi antigo e conduza seu povo do vapor ao átomo — economia, ciência, diplomacia, guerra, constituição, cidades e expedições.

- Jogo solo com modo **livre** ou **com objetivos**
- **Multiplayer online** para até 5 jogadores (Supabase)
- 97 tecnologias, 115 conquistas, épocas de 1850, 1914, 1960 e 2000

## Jogar

Abra o `index.html` no navegador, ou acesse o site publicado no GitHub Pages.

## Publicar e ativar o online

Veja o passo a passo em [COMO_PUBLICAR.md](COMO_PUBLICAR.md).

## Créditos dos mapas

Fronteiras, terra, lagos, estados e cidades: [Natural Earth](https://www.naturalearthdata.com/) (domínio público).
Os arquivos `js/geodata.js` e `js/geostates.js` são gerados a partir desses dados; as fronteiras das épocas antigas são montadas juntando países atuais.
